# Exemples de documents JIBI

JIBI utilise une spécification JSON intermédiaire. Le modèle remplit les
sections et les données ; Python choisit le thème, produit le HTML/CSS et le
convertit avec Chromium headless local en PDF.

Pour demander un exemple dans JIBI :

```text
Donne-moi un exemple de document JIBI.
```

ou :

```text
Crée un compte rendu avec le thème professionnel.
```

Les exemples complets sont dans `exemples_documents.json`. Les chemins
d'images importées sont relatifs à `donnees/fichiers`, par exemple
`imports/schema.png`.
